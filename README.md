# ⚒️ FORGE

**Forge your workflow. Build without friction.**

FORGE is a Python-powered command-line toolkit designed to simplify and accelerate modern software development workflows.

Instead of manually configuring every project from scratch, FORGE provides a unified CLI to scaffold frontend applications, backend APIs and complete full-stack SaaS monorepos.

### ✨ Features

- **Frontend generation:** Vue 3 + TypeScript and React + TypeScript powered by Vite.
- **Backend generation:** Fastify and NestJS with TypeScript.
- **SaaS monorepos:** Generate complete projects with separated frontend and backend applications.
- **Package manager support:** npm, pnpm and Yarn.
- **Developer utilities:** Environment diagnostics and project initialization.
- **Extensible architecture:** Modular generators designed to support future frameworks and workflows.

### 🛠️ Tech Stack

- Python 3.12+
- Typer
- Rich
- Vite
- Vue / React
- Fastify / NestJS
- npm / pnpm / Yarn

### 🚀 Philosophy

FORGE aims to eliminate repetitive setup tasks, standardize project structures and let developers focus on what matters most: building great software.

**Less setup. More building.**
